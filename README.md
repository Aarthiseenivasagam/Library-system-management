# Library Management System

## About the Project
A Library Management System developed using Python Flask and SQLite to manage library books.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite

## Features
- Add new books
- Search for books
- Issue books to students
- Return books
- Delete books
- View available and issued books separately
- Dashboard showing total, available, and issued book counts

## How to Run

1. Install Python.
2. Install Flask:
   `pip install flask`
3. Run the application:
   `python app.py`
4. Open your browser and visit:
   `http://127.0.0.1:5000`
